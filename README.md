# Breast Cancer Survival Analysis

## Project Overview

This project explores breast cancer patient survival using Python and statistical survival analysis techniques.

## Objectives

- Perform data cleaning and exploratory data analysis.
- Estimate survival probabilities using the Kaplan-Meier method.
- Compare survival distributions across cancer stages using the log-rank test.
- Investigate factors associated with survival using the Cox Proportional Hazards Model.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Lifelines
- Jupyter Notebook
